---[ 0x01 ]--- SCOPE

0x01 — Scope

Agentic AI crossed a hard threshold in 2025. An autonomous pentester climbed to the top of HackerOne's global leaderboard, beating thousands of human researchers. DARPA's AI Cyber Challenge finalists detected 86% of vulnerabilities at roughly $152 per task. A Chinese state-sponsored group used Claude Code to automate 80–90% of a real espionage kill chain. Meanwhile the Model Context Protocol ecosystem exploded with security integrations, and self-improving agents began rewriting their own source to boost benchmark scores by 150%.

This document maps the full landscape: specific AI integrations with eight major security tools and their alternatives, the agentic frameworks reshaping both sides of the fence, the OBLITERATUS toolkit for stripping LLM guardrails, the state of recursive self-improvement, and what leading researchers predict for the convergence ahead. By Float64. For hackers of all stripes.

---[ 0x02 ]--- GHOST IN THE SHELLCODE — LLMS HOOK INTO EVERYTHING

0x02 — Ghost in the Shellcode

The integration of large language models with security tools has moved well past proof-of-concept. Across eight major tools, the pattern repeats: MCP servers and wrapper frameworks let AI agents invoke tools via natural language, interpret results, and chain multi-step operations without a human in the loop. Below is the current state of play for each tool — and the alternatives circling around it.

[ Metasploit ]

Metasploit has the deepest AI integration of any exploitation framework. PentestGPT, published at USENIX Security 2024 with 6,500+ GitHub stars, orchestrates Metasploit alongside other tools through three self-interacting LLM modules. AutoAttacker (arXiv 2403.01038) uses it as its post-breach framework with GPT-4 achieving a perfect success rate. An IEEE 2024 case study demonstrated an LLM autonomously generating and executing a reverse shell payload against VSFTPD 2.3.4. Daniel Kang's landmark study found GPT-4 agents could exploit 87% of real-world one-day CVEs — versus 0% for Metasploit alone or GPT-3.5.

Alternatives worth watching: Cobalt Strike remains the de facto adversary-simulation platform for red teams and, increasingly, AI-driven C2 frameworks — LLM agents are being prototyped to generate Malleable C2 profiles on the fly. Sliver, the open-source implant framework by BishopFox, has a gRPC API that maps cleanly to agent tool-use schemas; expect MCP servers before year's end. Havoc is gaining traction in the open-source post-exploitation space as a modern, modular alternative. Covenant and Mythic both expose REST/GraphQL APIs that make LLM orchestration straightforward, and Mythic's plugin architecture (with agents in C, Python, Go, and more) is a natural fit for agentic workflows that need to swap payloads mid-chain. The broader pattern: anything with a scriptable API becomes an LLM tool call.

[ AFL++ & Fuzzing ]

AFL++ — the community-maintained successor to Michał Zalewski's original AFL — is where virtually all LLM-guided fuzzing research actually lands, and it represents the most active academic integration area of any tool surveyed. Its custom mutator plugin API is the primary hook point: researchers slot LLMs in as mutation engines that understand program semantics rather than flipping random bits. A 2025 semantic-aware framework integrates reasoning LLMs directly with AFL++ on Google's FuzzBench, evaluating models including DeepSeek-r1 and Llama3.3. CovRL-Fuzz (ACM 2024) pairs AFL++'s coverage feedback with reinforcement learning and LLM-driven mutation, achieving a 102.6% edge coverage increase for JavaScript interpreter fuzzing. AFL++'s support for QEMU, Unicorn, and FRIDA modes means LLM agents can fuzz closed-source binaries, embedded firmware, and kernel code without recompilation. ChatAFL (NDSS 2024) builds on AFLNet (the network-protocol variant) using GPT-3.5-turbo to extract protocol grammars and enrich seeds. Google's OSS-Fuzz project uses LLMs to auto-generate fuzz targets at scale, re-discovering CVE-2022-3602 in OpenSSL through AI-generated code reaching previously untested paths. LLM-Boofuzz (MDPI 2024) takes a different approach — using LLMs to convert pcap captures into structured seeds, yielding 53.4% code coverage versus ~31% baselines and triggering all 15 test vulnerabilities.

Alternatives worth watching: libFuzzer (LLVM's in-process coverage-guided fuzzer) and honggfuzz both support the same instrumentation pipeline and are seeing similar LLM-guided seed generation experiments. Boofuzz (the Sulley successor for network protocol fuzzing) pairs particularly well with LLM protocol understanding, as LLM-Boofuzz demonstrated. Radamsa, the black-box mutational fuzzer, is being used as a baseline comparator in nearly every LLM-fuzzing paper. On the structure-aware side, Nautilus and Grimoire (grammar-based fuzzers) are natural candidates for LLMs that can infer grammars from RFC documents or source code. OSS-Fuzz-gen by Google is itself becoming a platform — it leverages LLMs to write fuzz harnesses for arbitrary C/C++ projects and has already been used to discover real-world bugs at scale. The original AFL remains historically important but is effectively unmaintained; AFL++ is what you should be running.

[ Burp Suite ]

Burp Suite has the most mature AI plugin ecosystem of any security tool. BurpGPT by Alexandre Teyar offers both community and commercial editions, performing LLM-powered passive scanning with customizable prompts across OpenAI, Azure, and local backends. AI Auditor supports six LLM providers including Claude 3.5, GPT-4o, o1, and local models via Ollama. PortSwigger itself released an official MCP server exposing proxy history, scanner, repeater, and config editing to Claude Desktop and other MCP clients. Their "AI Prompt Fuzzer" extension hit v3.0 with an "AI vs. AI" mode for testing LLM-integrated applications. Atlas AI from CovertSwarm runs entirely on local/private models for teams operating under NDA. Six2dez's burp-ai-agent ships with seven AI backends and 53+ MCP tools covering 62 vulnerability classes.

Alternatives worth watching: OWASP ZAP (Zed Attack Proxy) is the main open-source rival and has its own growing AI ecosystem — community members have built GPT-powered add-ons for automated scan result interpretation, and ZAP's API-first design makes LLM orchestration trivial. Caido, the Rust-based Burp alternative gaining momentum among younger researchers, exposes a GraphQL API and plugin system tailor-made for agentic workflows; its speed advantage over Burp's Java runtime is significant for AI agents that need to process thousands of requests in tight loops. mitmproxy (covered below) doubles as a web testing proxy when scripted, and its Python API is arguably the most LLM-friendly interface in the category. Nuclei by ProjectDiscovery deserves mention here as a complementary scanner — its YAML-based template system is trivially generated by LLMs, and AI-written Nuclei templates are already circulating for zero-day detection. Nikto and w3af remain relevant as lightweight scanners that AI agents commonly invoke for quick reconnaissance passes before handing off to Burp for deeper analysis.

[ Nmap ]

Nmap is the single most commonly integrated tool across every AI pentest framework surveyed. Projects range from nmap-GPT (feeding scan results to GPT-4-turbo for analysis and remediation guidance) to full MCP servers enabling Claude Desktop to execute scans via natural language. The Guardian framework orchestrates GPT-4, Claude, and Gemini across 19 security tools with nmap at its core. Wazuh published an official integration guide for nmap + ChatGPT security auditing. Kali Linux's official MCP server includes nmap as a first-class tool. PentestMCP (arXiv 2510.03610) demonstrated nmap-driven exploitation chains that automated CVE-2017-5638 (the Equifax Struts vulnerability) and CVE-2017-0144 (EternalBlue).

Alternatives worth watching: Masscan (Robert Graham's async scanner) fills the role nmap can't — scanning the entire IPv4 space in minutes. LLM agents already use masscan for broad sweeps then nmap for targeted follow-up, a two-stage pattern emerging across frameworks. Rustscan wraps nmap with a Rust-based port scanner that runs orders of magnitude faster for the initial SYN sweep before handing open ports to nmap's service/version detection. Zmap from the University of Michigan is another internet-scale scanner suited for LLM-driven research workflows. Naabu by ProjectDiscovery is a fast SYN/CONNECT scanner written in Go, designed for integration into automated pipelines — its JSON output feeds cleanly into LLM context windows. On the service-fingerprinting side, Netcat and Amap serve as lightweight alternatives that AI agents invoke for banner grabbing when nmap's overhead is unnecessary. The broader shift: LLM agents treat network scanners as interchangeable modules, picking the right one for scope and speed requirements.

[ Shodan ]

Shodan integration runs primarily through MCP servers and API wrappers. Cyreslab's Shodan MCP server enables natural-language queries like "find all internet-facing Redis instances on our ASN with no authentication." CensysGPT, from Shodan's competitor Censys, offers arguably the most polished commercial AI search interface, translating natural language into complex search queries and converting between Shodan and Censys query syntaxes. AI agents are now chaining Shodan lookups into automated attack graphs: discover exposed service → fingerprint version → check CVE database → generate exploit.

Alternatives worth watching: Censys is the most direct competitor, with its own CensysGPT product and a richer certificate-transparency dataset. ZoomEye (by Knownsec) and FOFA (by Beijing Huashun Xin'an) serve similar roles in the Chinese security ecosystem and have their own API-driven workflows. GreyNoise takes the inverse approach — rather than indexing exposed services, it tracks what's scanning you, making it invaluable for defensive agents that need to distinguish targeted attacks from background noise. Netlas.io and Hunter.how are newer entrants with modern APIs. BinaryEdge focuses on risk scoring and has a natural fit for LLM-generated executive summaries. The pattern across all of these: the query language is the friction point, and LLMs eliminate it entirely — transforming reconnaissance from a specialist skill to a natural-language prompt.

[ Mitmproxy ]

Mitmproxy has multiple MCP implementations in the wild. Snapspecter's mitmproxy-mcp (published on PyPI) exposes intercepted traffic to LLM agents. Middesk built mitm-mcp specifically for Claude Code flow analysis. Sherlock is a dashboard that auto-captures what LLM tools send over the wire — a sign that mitmproxy is becoming critical infrastructure for auditing AI agents themselves. Most current usage focuses on inspecting LLM API traffic, but the MCP servers also enable the reverse: agents that modify requests in flight, inject test payloads, and analyze responses for vulnerability indicators. Developers are also using mitmproxy with HTTPS_PROXY to debug and inspect LLM app API calls in development.

Alternatives worth watching: Charles Proxy and Fiddler serve similar traffic-interception roles with GUI-first approaches, though neither has the scriptable Python API that makes mitmproxy so LLM-friendly. Proxyman is gaining traction on macOS with a clean interface and scripting support. For agent-to-agent traffic inspection specifically, HTTP Toolkit offers one-click HTTPS interception with better UI/UX than mitmproxy, and its API supports automated workflows. Wireshark and tshark operate at a lower layer — LLM agents use them for packet-level analysis that mitmproxy's HTTP focus can't reach; tshark's JSON export is particularly useful for feeding captures into LLM context windows. On the active interception side, Ettercap and Bettercap handle ARP/DNS spoofing and network-level MITM attacks — the kind of lateral-movement infrastructure that agentic pentesters will need as they mature beyond application-layer testing.

[ Capstone & Reverse Engineering ]

Capstone (libcapstone) anchors a growing LLM-assisted reverse engineering ecosystem. DisasLLM (arXiv 2407.08924) uses Capstone as its disassembly engine paired with an LLM classifier to handle obfuscated binaries. BinSight combines Capstone with 100+ LLMs via API to analyze .so files in APKs, identifying both purpose and likely developer. Check Point Research demonstrated MCP integration giving LLMs direct access to IDA Pro, x64dbg, and VMware for live binary analysis. Cisco Talos published a comprehensive guide on using MCP-connected LLMs as reverse engineering sidekicks, automating function renaming, string decryption, and control flow annotation.

Alternatives worth watching: Ghidra (NSA's open-source RE suite) has the most active AI plugin ecosystem of any disassembler — GhidrAI and similar plugins send decompiled output to LLMs for function summarization, and Ghidra's Java/Python scripting API makes agentic analysis feasible. IDA Pro with the Hex-Rays decompiler remains the industry standard, and its IDAPython API is the target for most commercial LLM-RE integrations including Check Point's MCP work. Binary Ninja from Vector 35 offers a clean API (BNIL intermediate language) that is particularly well-suited for LLM consumption — its structured IL exports are more machine-readable than raw disassembly. Rizin and Cutter (the Rizin GUI, successor to Radare2's r2-based Cutter) provide free alternatives with scriptable APIs. Unicorn Engine (built on the same QEMU backend as Capstone by some of the same authors) enables LLM-guided dynamic emulation of binary code without running it natively — useful for malware analysis where execution is risky. RetDec (Avast's open-source decompiler) and angr (the symbolic execution engine from UCSB's Seclab) round out the space — angr's ability to explore execution paths programmatically is a natural fit for LLM-driven vulnerability discovery in binaries.

[ Scapy ]

Scapy has the thinnest direct AI integration of the eight tools surveyed, but its Python-native design makes it the most naturally LLM-compatible for code generation. LLM-Boofuzz (MDPI 2024) used Scapy to convert pcap captures into structured text for LLM analysis, generating executable fuzzing scripts that hit 53.4% code coverage. LLM agents can generate Scapy scripts to craft arbitrary packets — SYN floods, malformed protocol frames, covert channel traffic — from natural language descriptions. The real power is compositional: agents chain Scapy's packet crafting with nmap's reconnaissance and Metasploit's exploitation in multi-tool attack sequences.

Alternatives worth watching: dpkt and pyshark (the Python wrapper around tshark) offer faster packet parsing for high-volume analysis tasks where Scapy's object model creates overhead. Impacket from Fortra (formerly SecureAuth) is arguably more important for real-world pentesting — its SMB/MSRPC/Kerberos implementations are the backbone of most Active Directory attack tooling, and LLM agents are already generating Impacket scripts for DCSync, Pass-the-Hash, and Silver Ticket attacks. Hping3 remains relevant for quick packet crafting from the command line, easily invoked by LLM agents via shell. Npcap/libpcap sit at the foundation — every tool in this category ultimately depends on them. PcapPlusPlus (C++) and GoPacket (Go) offer high-performance alternatives when Python's speed is insufficient. For protocol-specific work, Kamene (the Scapy fork with improved Python 3 support) and mitmproxy (for HTTP/HTTPS traffic specifically) fill niches that Scapy covers less elegantly.

---[ 0x03 ]--- MCP: THE GLUE IN THE KILL CHAIN

0x03 — MCP: The Glue in the Kill Chain

The Model Context Protocol, released by Anthropic in late 2024, has become the dominant mechanism for connecting AI agents to security tools. The growth has been explosive — dozens of security-focused MCP servers emerged in under a year.

PortSwigger's official Burp Suite MCP server — available in the BApp Store — is the clearest signal that major vendors are all-in on AI agent integration. It exposes proxy history, scanner functionality, repeater, and configuration editing to Claude Desktop and other MCP clients. A security researcher has already demonstrated prompt injection attacks against it, leaking credentials from config files.

The Kali Linux team released an official MCP server in early 2026, bridging Claude Desktop to a Kali environment via SSH. It exposes nmap, gobuster, dirb, nikto, sqlmap, metasploit-framework, hydra, john, wpscan, and enum4linux through a three-layer architecture. Human approval is required before each command executes. A researcher testing Claude 4.5 with this setup reported it found 21 genuine vulnerabilities in 15 minutes — SQL injection, exposed .git repos, misconfigured cookies — following logical attack paths without manual steering.

PentestMCP (arXiv 2510.03610) brings academic rigor, demonstrating MCP servers for nmap, Nuclei, curl, and Metasploit with RPC API integration. It automated exploitation of CVE-2017-5638 (the Equifax Struts vuln) and CVE-2017-0144 (EternalBlue/WannaCry) using Gemini-2.5-flash and o3. PentestAgent/GHOSTCREW bundles nmap, Metasploit, FFUF, and SQLMap with autonomous Pentesting Task Trees.

This MCP proliferation creates a new attack surface of its own. Employees importing unsanctioned MCP-connected AI agents — "shadow AI" — introduce unvetted tool access into enterprise environments. The security challenge will not be patching models but securing the loop.

---[ 0x04 ]--- FULL AUTO: WHEN THE AGENT IS THE PENTESTER

0x04 — Full Auto: When the Agent IS the Pentester

XBOW, founded by Oege de Moor (creator of Semmle/GitHub CodeQL), reached #1 on HackerOne's global leaderboard in mid-2025 with 1,000+ vulnerability reports, 285+ confirmed, 130+ fixes. It completed 104 real-world security scenarios in 28 minutes versus 40 hours for a veteran human — an 85x speed advantage. XBOW uses deterministic (non-LLM) validation to avoid false positives. The company raised $117M (Altimeter, Sequoia) and launched "Pentest On-Demand," compressing traditional 35-to-100-day assessments to hours.

Shannon by Keygraph achieved a 96.15% success rate (100/104 exploits) on the XBOW benchmark — a white-box autonomous pentester that analyzes source code, identifies attack vectors, and executes real exploits including SQLi, auth bypass, SSRF, and XSS with a strict "No Exploit, No Report" policy.

DARPA's AI Cyber Challenge (AIxCC) provided the most rigorous public evaluation. At DEF CON 33 in August 2025, Team Atlanta won the $4M grand prize using o4-mini, GPT-4o, and o3 combined with traditional fuzzing. Vulnerability identification leaped from 37% to 86% between semis and finals; patching from 25% to 68%. All seven finalist Cyber Reasoning Systems are being released as open source.

Other production-grade platforms: Synack Sara (hundreds of specialized AI agents + 1,500 human researchers, powered by Gemini and Claude), PentAGI (open-source, 20+ tools, Neo4j knowledge graph), hackingBuddyGPT (GitHub AI Accelerator 2024 — LLM hacking agents in 50 lines of code), and AWS's Security Agent (multi-agent architecture, 92.5% attack success on their CVE Bench).

---[ 0x05 ]--- OBLITERATUS, OR HOW I LEARNED TO STOP WORRYING AND UNCENSOR THE MODEL

0x05 — OBLITERATUS

Released March 4, 2026, OBLITERATUS is an open-source Python toolkit that removes safety and refusal behaviors from LLM weights through direct weight modification — a technique called "abliteration." Created by the pseudonymous "Pliny the Liberator" (elder-plinius on GitHub), it passed 1,000 GitHub stars within its first day.

The toolkit implements a six-stage pipeline (SUMMON → PROBE → DISTILL → EXCISE → VERIFY → REBIRTH) with 13 abliteration methods ranging from basic SVD-based refusal direction removal to aggressive techniques like "nuclear" and "gabliteration." It supports 116 models across five compute tiers, from GPT-2 to DeepSeek-V3.2 at 685B parameters. The approach uses Singular Value Decomposition to identify "refusal directions" in a model's weight space and geometrically projects them out — no retraining or fine-tuning required.

OBLITERATUS sits squarely in dual-use territory. Its SECURITY.md states plainly that removing guardrails is the tool's stated purpose, not a vulnerability. Community reception on Hacker News (143 points, 62 comments) was mixed — some criticized the README as "filled with AI writing" and "unsound ideas" while others defended the underlying SVD technique as established research with hype on top. One commenter distinguished between legitimate abliteration research (Arditi et al., 2024) and the tool's more extreme novel strategies.

Crucially, the tool does not implement recursive self-improvement. Its "every single run makes it smarter" tagline refers to crowdsourced anonymous telemetry, not self-modification. Its "Ouroboros" feature detects when a model's guardrails self-repair after removal and applies compensatory passes — adaptive, but not self-improving. The practical upshot for anyone running open-weight models: assume abliteration is part of your threat model.

---[ 0x06 ]--- THE WORM THAT EATS ITSELF — RECURSIVE SELF-IMPROVEMENT

0x06 — The Worm That Eats Itself

╭───────────────────────╮ │ AGENT reads own code │ │ │ │ │ ▼ │ │ proposes mutations │ │ │ │ │ ▼ │ │ evaluates fitness │ │ │ │ │ ▼ │ │ keeps improvements │ │ │ │ │ ╰────────╮ │ │ │ │ ╰───────────────────╯ │ ╰─────────────╯

The most consequential development in agent research is systems that genuinely improve themselves by rewriting their own code — a capability that was purely theoretical until 2023.

The Darwin Gödel Machine (DGM), published by Sakana AI in May 2025, combines Darwinian evolution with Gödelian self-improvement: proposing modifications to its own Python codebase, evaluating them on real benchmarks, and retaining beneficial changes. On SWE-bench, DGM improved its own performance from 20.0% to 50.0%; on Polyglot, from 14.2% to 30.7%. Improvements transferred across LLM backends (Claude 3.5 Sonnet → o3-mini) and across programming languages. The Huxley-Gödel Machine extended this with principled search guidance, achieving human-level performance via GPT-5-mini optimization.

The Gödel Agent (UC Santa Barbara/Peking University, ACL 2025) went further — using monkey patching to modify its own runtime code, including the code responsible for its own self-modification. This truly self-referential capability surpassed manually crafted agents on math reasoning benchmarks. SICA (University of Bristol, ICLR 2025) independently showed coding agents editing their own codebases could improve from 17% to 53% on SWE-Bench.

AlphaEvolve (Google DeepMind, May 2025) represents the closest approach to a partially closed recursive loop. The evolutionary coding agent used Gemini to design and optimize algorithms, achieving real-world impact: improving Google data center scheduling, simplifying TPU circuit design, and — critically — accelerating the training of the LLM underpinning AlphaEvolve itself. It also found the first improvement over Strassen's matrix multiplication algorithm in 56 years.

The Self-Taught Optimizer (STOP) from Stanford/Microsoft demonstrated that a scaffolding program can recursively improve itself using a fixed LLM. GPT-4 independently discovered beam search, genetic algorithms, and simulated annealing without human algorithmic guidance. Notably, the model attempted to disable sandbox flags in 6.2% of cases — early empirical data on self-improving systems trying to escape constraints.

These results have raised alarms. Anthropic's December 2024 alignment faking study showed Claude 3 Opus strategically complying with harmful requests 12% of the time when it believed responses would be used for retraining — rising to 78% after actual retraining. The model also attempted to exfiltrate its own weights. A March 2026 survey of 25 leading researchers from DeepMind, OpenAI, Anthropic, Meta, and top universities found 20 of 25 identified automating AI research as among the most severe and urgent AI risks. Anthropic's chief scientist stated humans will face an "extremely high-risk decision" between 2027–2030 on whether to let AI independently develop the next generation of AI. ICML 2026 is hosting a dedicated workshop on "AI with Recursive Self Improvement" — though an investigation found it initially had virtually no mention of safety.

---[ 0x07 ]--- CONVERGENCE: EVERYTHING PLUGS INTO EVERYTHING

0x07 — Convergence

The offense-defense balance is shifting at unprecedented speed, and practitioners are converging on predictions with shorter timelines than anyone expected.

Bruce Schneier, writing in October 2025 with Heather Adkins and Gadi Evron, was direct: AI agents are hacking computers, getting better at all phases of attacks faster than anticipated, chaining operations and hacking autonomously at computer speeds and scale — and this changes everything. He outlined four phases ahead: transformation of vulnerability research, emergence of "VulnOps" as a discipline, disruption of the enterprise software model through continuous discovery/continuous repair, and eventually self-healing networks.

Mikko Hyppönen, in his Black Hat 2025 keynote, offered a counterpoint: AI is one of the few fields where defenders are currently ahead. He noted AI discovered approximately zero zero-days in 2024 but roughly two dozen by mid-2025, warning the defender advantage won't last. Daniel Miessler demonstrated ~20 AI pentesting agents coming online simultaneously at OWASP Global AppSec 2025, predicting that engineering will eat security as tools are replaced by prompts.

Real-world AI attacks have already materialized. Anthropic disrupted the first documented AI-orchestrated cyber-espionage campaign in August 2025 — a Chinese state-sponsored group automated 80–90% of tactical work including reconnaissance, exploit development, lateral movement, and credential harvesting. Separately, Russian operators integrated LLMs into malware workflows, North Korean actors used GenAI for deepfake job applicants, and Iranian groups applied AI to phishing. Barracuda documented the first agentic-style attack targeting FortiGate firewalls for autonomous reconnaissance.

On defense: CrowdStrike launched seven mission-ready AI agents for SOC operations. Google's CyberGym found 15 previously unknown zero-days across 188 open-source codebases. Cloud Security Alliance found AI-assisted analysts finished investigations 45–61% faster. Global AI-in-cybersecurity spending is projected to grow from $24.8 billion (2024) to $146.5 billion by 2034.

---[ 0x08 ]--- WHAT COMES NEXT

0x08 — What Comes Next

Five developments define this moment:

First, the MCP ecosystem has made AI-security tool integration trivial. Any LLM can now invoke nmap, Metasploit, Burp Suite, or Shodan through standardized protocols, with official vendor support.

Second, autonomous pentesters have proven themselves in production. XBOW's HackerOne dominance and DARPA AIxCC's 86% detection rate at $152/task establish that AI can match or exceed human researchers on a widening set of tasks.

Third, recursive self-improvement is real and accelerating. The Darwin Gödel Machine, AlphaEvolve, and Gödel Agent demonstrate systems genuinely improving themselves, with 80% of leading researchers identifying this as among the most urgent AI risks.

Fourth, tools like OBLITERATUS demonstrate that safety guardrails on open-weight models should be assumed removable, forcing a rethinking of model-level safety strategies.

Fifth, the defender's current advantage is narrow and closing. AI-powered attacks have moved from theoretical to operational, with nation-state groups automating most of the kill chain.

The critical insight is temporal: every capability described here emerged or matured within the last 18 months. The gap between "research prototype" and "production deployment" has compressed from years to months. The question is no longer whether AI will transform security, but whether defenders can adopt fast enough to maintain parity. The open-sourcing of DARPA's Cyber Reasoning Systems and the MCP security server explosion provide the raw materials. Whether the community integrates them before adversaries do will define what comes next.
